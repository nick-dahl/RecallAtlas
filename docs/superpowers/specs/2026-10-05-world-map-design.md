# World Map course — Design Spec

**Date:** 2026-10-05
**Status:** Approved design (brainstormed with the user), pending spec review
**Parent spec:** `2026-10-01-recall-atlas-design.md`. Everything there applies unless overridden here.

## 1. Summary

World Map is the second course. It covers the same 197 countries and 13 learning regions as World Flags **plus 11 dependent territories** (208 items, see §3.1), with mastery tracked independently. Learners locate countries on a map, name a highlighted country, and give its capital.

Engine changes are small and general; the substantial new work is map geometry and map UI. Answers never leak to the browser:
- **Base maps** carry no identifiers.
- **Clicks** are graded server-side from coordinates.
- **Per-question overlays** use opaque ids.

## 2. Decisions

| # | Decision | Choice |
|---|---|---|
| M1 | Prompts per country | **Find it** (name → location), **Name it** (highlighted → name), **Capital** (highlighted → capital): 624 prompts (208 items × 3) |
| M10 | Territories | 11 notable dependent territories are World Map items (not World Flags), see §3.1 |
| M2 | Ladder | See §4 (Find: outlined candidates → open click; Name and Capital: text choices → typed) |
| M3 | Framing | Fixed, pre-framed views, no pan or zoom. The learning region for rungs 1–2 and for Name/Capital; the continent for Find at recall |
| M4 | Click grading | Exact hit with padded targets for small countries; another country = wrong plus a confusion; ocean = wrong, no confusion |
| M5 | Capitals | One displayed capital, plus accepted official alternates and spellings; contested cases carry a note |
| M6 | Course home | A mastery map (the countries fill in as learned) replaces the stamp album for this course |
| M7 | Placement | One "click X" per country. A correct click graduates **Find + Name**; Capital is always learned in study |
| M8 | Map architecture | Static, id-free base maps per frame plus server-side hit-testing (approach A) |
| M9 | Build order | Plan 5: data + engine (no UI). Plan 6: UI + e2e + review + deploy |

## 3. Content & data

`content/countries.json` remains the single source of country data. New fields:

| Field | Source |
|---|---|
| `capital` (displayed) | world-countries `capital[0]`, overridden by `scripts/capital-overrides.ts` |
| `capitalAliases` | overrides: other official capitals and spelling variants |
| `capitalNote` | overrides, for contested status |
| `neighbors` | world-countries `borders` (cca3 → our keys) |
| `nearby` | the 6 nearest countries by `latlng` great-circle distance (always present; covers islands) |
| `latlng` | world-countries |

**Capital overrides** (initial list; the build validates them):

| Country | Displayed | Also accepted / note |
|---|---|---|
| ZA | Pretoria | Cape Town, Bloemfontein |
| BO | Sucre | La Paz |
| SZ | Mbabane | Lobamba |
| NL | Amsterdam | The Hague is not accepted (seat of government, not capital) |
| IL | Jerusalem | note: status disputed |
| PS | Ramallah | note: East Jerusalem is the claimed capital |
| UA | Kyiv | Kiev |
| MN | Ulaanbaatar | Ulan Bator |

The build fails if two countries accept the same normalized capital spelling, or if any country lacks a capital. Extra capitals listed by world-countries (`capital[1..]`) become aliases too.

### 3.1 Territories (amendment, 2026-10-05)

The user asked to include territories. `MAP_TERRITORIES` in `scripts/content-config.ts` lists them; they are records in `content/countries.json` with `territory: true`. World Flags filters them out (it stays at 197); World Map includes them.

| Key | Territory | Group | Capital |
|---|---|---|---|
| GL | Greenland | North & Central America | Nuuk |
| BM | Bermuda | North & Central America | Hamilton |
| PR | Puerto Rico | Caribbean | San Juan |
| AW | Aruba | Caribbean | Oranjestad |
| CW | Curaçao | Caribbean | Willemstad |
| GF | French Guiana | South America | Cayenne |
| FK | Falkland Islands | South America | Stanley |
| FO | Faroe Islands | Western & Northern Europe | Tórshavn |
| NC | New Caledonia | Oceania | Nouméa |
| PF | French Polynesia | Oceania | Papeete |
| GU | Guam | Oceania | Hagåtña |

Each is its own world-atlas feature except French Guiana, which is carved out of France's multipolygon by a split rule. Other territories (and Western Sahara) remain drawn but not clickable.

**Map geometry** (generated by the content build, committed like the flags):
- **Source:** Natural Earth 1:50m admin-0 via `world-atlas`. Breakaway regions merge into their UN parent (Somaliland → SO, N. Cyprus → CY, etc.). Mapping rules for disputed or special cases live in one reviewed config: XK, PS, TW, EH (excluded from the course; its land is drawn but not clickable), and Pacific microstates.
- **Frames:** 13 region frames and 5 continent frames. Each is a fitted projection (Natural Earth or Equal Earth family) with a fixed viewBox.
- **Each frame produces:**
  - `public/maps/<frame>.svg`: the base map. Land, borders and sea only; no ids, titles or names. Immutable cache.
  - `content/maps/<frame>.hit.json`: server-only. Projected polygons per country key, plus circle markers (center, radius) for countries smaller than ~8 px in that frame.
- **Course-home reference map:** `public/maps/world-atlas.svg` with per-country ids. It is used **only** on the course home and never in a question.

**Validation (fails the build):**
- Every course country has a shape or a marker in its region frame and its continent frame.
- A representative interior point per country (a pole of inaccessibility, not the centroid) hit-tests back to that country in each of those frames.
- Base SVGs contain no country identifiers or names.
- Each base SVG is ≤ 80 KB.

## 4. Prompts, ladder, formats

| Prompt | Rung 1 | Rung 2 | Rung 3 (recall; also review and exam) |
|---|---|---|---|
| `find` | `map-pick`: 4 outlined candidates on the region map | `map-pick`: 6 outlined, hard distractors | `map-click` on the continent map |
| `name` | `mc-text` (4 names), country highlighted on the region map | `mc-text` (6, hard) | `typed` name |
| `capital` | `mc-text` (4 capitals), highlighted on the region map | `mc-text` (6 capitals, hard) | `typed` capital |

- **Hard distractors:** personal confusions → `neighbors` → `nearby` → same region → random. These are the course's item `lookalikes`.
- **Placement:** `find` at rung 3 (`map-click`). A correct answer graduates `find` and `name`.
- **Exam:** unchanged rule. Each country once, a random prompt, rung 3.

## 5. Engine changes (`lib/engine`, kept pure)

1. **Answer field per prompt type:**
   - `PromptTypeDef.answerField?: 'name' | 'capital'` (default `'name'`).
   - `Item.answers?: Record<string, { text: string; aliases: string[] }>`.
   - `gradeTyped(input, target, items, field = 'name')` grades against the chosen field with all existing rules (typo tolerance, transpositions, another item wins ties).
   - A typed answer equal to another country's capital is a confusion with that country.
   - Distractor labels for `mc-text` use the answer field. In practice the presenter shows the field; the engine still deals in item keys.
2. **Formats:** `Format` gains `map-pick` (choices) and `map-click` (no choices).
3. **Placement subset:** `CourseDef.placementGraduates?: string[]` (default: all prompt types). `applyPlacementAnswer` takes the course and graduates only those prompts.

Existing flag behavior is unchanged (defaults). All existing engine tests must still pass.

## 6. Map module (`lib/map`, pure, server-side)

- `frameFor(courseItem, promptType, rung) → FrameId`: the continent for `find` at rung 3, otherwise the item's region frame.
- `loadFrame(frameId)`: server-only, reads the base SVG metadata (viewBox, url) and the hit data (cached).
- `hitTest(frame, x, y, renderedWidth) → itemKey | null`:
  - `x` and `y` are normalized to [0,1] in the frame's viewBox.
  - Point-in-polygon against projected outlines first.
  - Otherwise the nearest marker within 12 CSS px (converted to viewBox units through `renderedWidth`).
  - Otherwise `null` (ocean).
- `gradeClick(pending, point, frame) → AnswerGrade`:
  - Correct if the hit is the target.
  - Wrong with `answeredItemKey = hit` if another country.
  - Wrong with `null` if ocean.

## 7. Services & views

- **`AnswerResponse`** gains `{ kind: 'point'; x: number; y: number; width: number }`. Validation: finite, `0 ≤ x,y ≤ 1`, `100 ≤ width ≤ 4000`.
- **`PendingQuestion`** gains `frame?: FrameId`, chosen at issue time. Grading uses the frame the learner actually saw.
- **`gradeSubmission`**: `map-click` + `point` → `gradeClick`. `map-pick` uses the existing choice path.
- **`QuestionView.map?`** = `{ baseUrl, viewBox, highlight?: string, candidates?: { id, d, labelX, labelY }[] }`. Path data is projected in the frame's coordinates. Candidates carry opaque choice ids (the same as `choices`).
- **`FeedbackView.map?`** = `{ frame, correct: string, given?: string }` (outline paths), plus `capital`/`capitalNote` for Capital prompts.
- **Presenter:** a new `mapPresenter`.
  - The prompt shows the country name for `find`, and the highlight plus "Which country is this?" / "What's its capital?" otherwise.
  - Choice labels use the answer field.
  - `item()` returns name and flag (flags remain a familiar anchor in feedback and end screens).
- **Leak rules:** for a Find question, the view contains the target's name only. For Name and Capital, the view contains no country names except choice labels (which always include distractors). No item keys ever appear.
- **Course definition:** `WORLD_MAP` in `lib/content/world-map.ts`:
  - `placementPromptType: 'find'`
  - `placementGraduates: ['find','name']`
  - `lookalikes` = neighbors ∪ nearby
  - registered in `lib/content/registry.ts`

## 8. UI (Plan 6)

- **`<MapFrame>`:** the base SVG as `<img>`, plus an absolutely positioned SVG overlay for the highlight, candidates (numbered labels) and feedback outlines. Clicks are reported as normalized coordinates. Highlight color is the accent. Small CSS "ink-in" and pulse animations, with reduced motion respected.
- **Renderers:**
  - `MapPick`: numbers `1`–`6` and clicks on outlines.
  - `MapClick`: crosshair cursor, no hover highlight, `Esc` = "I don't know".
  - `Prompt` renders a map when `view.map` is present (so `mc-text`/`typed` work unchanged).
- **Feedback:** the correct country pulses green and the clicked one flashes red. The panel text reads e.g. "That's Bolivia; Peru is here", with the capital and note for Capital prompts.
- **Course home:** the mastery map, with countries filled by tile state, a gold outline for mastered, dots for tiny countries, and a hover summary (Find/Name/Capital). The readiness meter, confusions and last exam are reused.
- **Dashboard:** the World Map card goes live.

## 9. Testing

- **Content build:** the validations in §3.
- **Unit:**
  - `hitTest` (inside, border, ocean, marker padding scaling) and `gradeClick`.
  - Capital grading (aliases, typos, other-capital confusion).
  - `answerField` defaults (flags unchanged), `placementGraduates`, map distractors.
  - `point` validation.
  - Map presenter leak test.
- **Engine:** a 30-day learner simulation on `WORLD_MAP`.
- **Integration:** a map placement and exam flow through `SupabaseStore` (the click helper uses hit data to find interior points).
- **E2E (Plan 6):**
  - Placement by clicking and an exam by clicking.
  - One deliberate wrong click to check feedback.

## 10. Out of scope

Zoom and pan; mobile pinch gestures; a dedicated dark-mode map palette; capitals as a standalone course; territories beyond the §3.1 list (those are drawn as land but are not clickable answers).

## 11. Implementation notes (Plan 5)

Decisions made while planning, against the real data:
- **Continent frames:** 6, not 5. The Americas are split into North America (with Central America, the Caribbean and Greenland) and South America; one Americas frame would be a tall portrait map with unreadable islands.
- **Projection:** each frame is an azimuthal equal-area projection centred on a hand-picked lon/lat extent (`lib/map/frames.ts`), clipped to its viewBox (1000 units wide). Russia is clipped to its European part in European frames.
- **Unmapped data:** Kosovo, Somaliland and N. Cyprus have no ISO id in world-atlas and are mapped by name. Tuvalu is absent at 1:50m and is a marker-only item at its world-countries `latlng`.
- **Hit-test order:** inside a marker dot → inside a polygon → nearest marker within the 12 px pad. The first tier keeps enclaves (San Marino, Vatican) clickable without letting the pad swallow clicks on the surrounding country.
- **Distractors:** rung 1 uses a new `local` mode (same group first, then others). Every map question restricts distractors to items drawn in its frame (`eligible`), so candidates are always visible.
- **Partially placed items:** `newItemsInOrder` now returns items with *any* new prompt, so a placed item still gets an intro card for its capital. Placement itself only queues items whose prompts are all new.
- **Course-home map:** `content/maps/world-atlas.json` (paths per key) instead of an SVG with ids, so the course home can render it inline with tile colours.
